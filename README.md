# QRCheck

PWA para registrar entrada y salida de empleados mediante escaneo de código QR desde una tablet montada en pared.

## Idea general

- La tablet queda fija en la pared, bloqueada en modo kiosko mostrando la PWA.
- Cada empleado tiene un QR personal (credencial, gafete, etc.).
- Al escanear su QR, el sistema registra la hora de entrada o salida automáticamente.
- Panel de administración para consultar asistencia por empleado/fecha.
